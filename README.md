# Estrutura de Dados 1

Repositório destinado aos códigos, exercícios e implementações desenvolvidos ao longo da disciplina **Estrutura de Dados 1**, do curso de **Engenharia de Software** da **Universidade Tecnológica Federal do Paraná (UTFPR) — Campus Cornélio Procópio (CP)**.

## 📚 Sobre a disciplina

A disciplina aborda conceitos fundamentais de estruturas de dados e sua aplicação no desenvolvimento de software, explorando diferentes formas de organização, armazenamento e manipulação de dados.

Este repositório reúne os materiais práticos desenvolvidos durante as aulas, incluindo os slides utilizados, servindo como registro dos estudos e como material de consulta.

## Conteúdos

Entre os principais conteúdos trabalhados estão:

- Estruturas de dados básicas
- Vetores e matrizes
- Listas encadeadas
- Pilhas
- Filas
- Árvores
- Algoritmos de busca
- Algoritmos de ordenação
- Alocação dinâmica de memória
- Ponteiros e estruturas
- Análise de complexidade de algoritmos

> O conteúdo pode variar conforme o andamento da disciplina e as atividades propostas.

## Tecnologias

As implementações presentes neste repositório utilizam principalmente:

- **C** — linguagem utilizada nas implementações
- **Git** — controle de versão
- **GitHub** — hospedagem e organização do código

## 📁 Estrutura do repositório

A organização dos arquivos segue a divisão das atividades e conteúdos desenvolvidos durante a disciplina.

A estrutura pode ser atualizada conforme novos conteúdos e exercícios forem adicionados.


🎯 Objetivo
O objetivo deste repositório é centralizar as implementações realizadas durante a disciplina, facilitando:

A organização dos exercícios
A revisão dos conteúdos
O acompanhamento da evolução durante a disciplina
A consulta às implementações de diferentes estruturas e algoritmos
A prática de conceitos fundamentais de programação
